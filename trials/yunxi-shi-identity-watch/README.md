# Window Watch

A self-contained, single-page identity investigation game built with HTML, CSS, and vanilla JavaScript.

## Static upload

Upload `index.html`, `styles.css`, and `game.js` together in the same directory. The game has no build step, package installation, server-side runtime, or external assets.

For a local preview, open `index.html` directly in a modern browser.

## Controls

- Hold and move over the license portrait to use the 3× magnifier.
- **A** or the green button: let the traveler pass.
- **D** or the red button: incinerate an impostor.
- Reach five correct decisions to win. One mistake ends and resets the shift.
