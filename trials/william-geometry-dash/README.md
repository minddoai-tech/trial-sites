# Neon Run

A self-contained, three-level browser platform game with a parallax city foreground and several obstacle shapes. The runner changes shape each time a run starts and as you progress through levels. Open `index.html` in a modern web browser to play; no install or build step is needed.

**Controls:** Press Space to start, jump, retry, or continue. Your runner moves automatically. Clear each level's hazards to advance; hitting one restarts the current level.
