# Last Light

A self-contained 2D browser shooter with five escalating levels.

## Run

Upload all five project files together, or open `index.html` in a modern browser. No build step, server, package installation, or internet connection is required.

## Controls

- **A / D** — move
- **Space** — jump
- **Ctrl** — sprint
- **Shift** — shoot
- **V** — reload
- **E** — show credits and potions
- **H** — use a healing potion
- **C** — collect nearby ammo or weapon boosts

Clear every hostile across the full scrolling sector to advance. Bullets stop at walls and platforms. Between sectors, visit the supply base to spend credits on damage, health, magazine capacity, and healing potions. Faster clears award a larger credit bonus.
