# Skyline Run

A small single-page browser game. Open `index.html` in any modern browser to play.

- Choose Comet, Aurora, or Mintwing from the aircraft hangar.
- Use the left and right arrow keys to steer.
- Collect gold coins, avoid the trees, and watch your score climb each second.
- You have three wing hearts; after a collision there is a brief grace period so the flight stays playable.
- Use Restart to begin a new mission or Exit mission to return to the menu.
