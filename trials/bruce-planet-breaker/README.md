# Pixel Party

Pixel Party is a static, school-friendly arcade landing page with three vanilla JavaScript mini-games:

- Fast Food Chef
- Floodbound
- Meteor Shooter

The standalone Planet Breaker space shooter lives at `space-shooter/index.html` and includes its own local assets.

## Run locally

Open `index.html` directly, or serve this folder with any static file server. No build step or dependencies are required.

## GitHub Pages

Push the repository to GitHub, then choose **Settings → Pages → Deploy from a branch** and select the branch that contains these files.
