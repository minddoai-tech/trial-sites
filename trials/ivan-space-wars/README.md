# Space Wars

A self-contained single-page browser game with no build step or dependencies.

## Run locally

Open `index.html` in a modern browser.

## Controls

- `←` / `→` or `A` / `D` — move the player ship
- `Space` — fire; hold it for automatic fire
- `R` — restart the mission

Break three enemy cores across three levels. Each level increases enemy fire rate, and collecting the cyan power core temporarily activates rapid fire.
